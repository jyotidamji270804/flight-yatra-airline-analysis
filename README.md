Flight Yatra is a Python-based airline data analysis project 
that explores booking patterns and ticket pricing across major 
Indian airlines like IndiGo, Air India, SpiceJet and Vistara. 
The project uses Pandas and NumPy for data cleaning and analysis, 
Matplotlib and Seaborn for static charts, Plotly for an 
interactive 12-chart dashboard, and Folium for a flight route 
map of India. Key findings include IndiGo having the highest 
number of flights, Vistara being the most expensive airline 
with an average price of Rs 6,325, SpiceJet being the most 
affordable at Rs 2,850, and Delhi to Mumbai being the most 
popular route. The project covers the complete data analysis 
pipeline from raw data collection to interactive visualization.
